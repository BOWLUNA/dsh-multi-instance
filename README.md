# dsh-persona-library

**状态：规划中 · Status: planned.** 尚无可用版本。

## 要解决什么

dsh 的系统提示词通常只有"当前这一套"。但同一个人常需要多套身份：写代码的、写小说的、做翻译的、审代码的——每套还要能带自己的工具开关。

## 计划做什么

一个**人格库**：

- 保存多套人格（系统提示词 + 可选的模型/工具集偏好）
- 一键切换，**新会话即生效**
- **导入导出**成文件，方便备份与分享给别人
- 与 [dsh-custom-mode](https://github.com/BOWLUNA/dsh-custom-mode) 配合：那里管"当前人格的内容与开关"，这里管"多套人格的收藏与切换"

## 不做什么

- **不**替代 agent preset 机制：人格最终仍落到 dsh 自己的 preset 上，不另造一套运行时
- **不**托管人格市场、**不**上传用户的人格内容
