# dsh-prompt-hub

**状态：规划中 · Status: planned.** 尚无可用版本。

> 提示词库 / 人格库（prompt & persona hub）。给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）管理**多套系统提示词**：保存、一键切换、导入导出、分享给别人。

## 要解决什么

dsh 的系统提示词通常只有"当前这一套"。但同一个人常同时需要好几套身份：

- 写代码的、审代码的
- 写小说/剧本的
- 做翻译、做校对的
- 跑角色扮演的

每套往往还要带**自己的工具开关**。现在切换靠手改配置文件，改完还得记住上次是哪套。

## 计划做什么

一个**提示词库**：

- 保存多套提示词（名字 + 内容 + 可选的模型/工具集偏好）
- **一键切换**，新会话即生效
- **导入 / 导出**成文件：备份、跨机器同步、分享给别人
- 按场景**分组与检索**（提示词一多，找起来就是真问题）
- 与 [dsh-custom-mode](https://github.com/BOWLUNA/dsh-custom-mode) 配合：那边管**当前这套的内容与逐行开关**，这边管**多套之间的收藏与切换**

## 不做什么

- **不**另造人格运行时：最终仍落到 dsh 自己的 agent preset 机制上
- **不**托管公共提示词市场、**不**上传用户的提示词内容（本项目没有服务器）
- **不**做提示词的"自动优化"（那是另一类插件）

## 和同类项目的分工

目录里已有若干相关项目，定位不同：

- `dsh-prompt-library`（11★）：偏"片段收藏"
- 综合性管理面板（如 Armory 一类）：提示词只是它的一块
- 本项目：**只做提示词/人格这一件事**，且与 dsh 原生 preset 机制对齐
